# Paper 26.3 — серверный пак для Windows

Готовый набор файлов, чтобы поднять свой Minecraft-сервер (Java Edition) на ядре
**Paper 26.3** на обычном ПК с Windows. Ядро (`paper.jar`) качается автоматически
при первом запуске — вручную ничего искать не надо.

Всё лежит в папке [`server/`](server/). Скопируй её целиком на Windows-машину
и запусти `start.bat` двойным щелчком.

> **Скачать готовый архив:**
> [servermmo-paper-26.3-server-pack.zip](https://github.com/oshee-g/servermmo/releases/latest/download/servermmo-paper-26.3-server-pack.zip)
> (все плагины, ресурспак и скрипты раздачи внутри).

---

## Что входит в пак

| Файл | Что делает |
|---|---|
| `server/start.bat` | **главный запуск.** Проверяет наличие ядра, качает его при необходимости, создаёт `eula.txt`, проверяет Java и запускает сервер. После остановки предлагает перезапуск |
| `server/settings.bat` | все настройки: версия Paper, объём памяти, путь к Java, автоперезапуск |
| `server/update.bat` | обновить ядро Paper до свежего билда выбранной версии |
| `server/backup.bat` | бэкап миров, плагинов и конфигов в папку `backups/` |
| `server/server.properties` | настройки мира, порта, мотд, белого списка (уже заполнены разумными значениями) |
| `server/eula.txt` | согласие с EULA — уже `true`, чтобы сервер стартовал без ручной правки |
| `server/plugins/` | папка для плагинов `.jar` — там уже лежат четыре плагина **ServerMMO** |
| `server/resourcepack/` | `servermmo-hud.zip` — ресурспак с рамкой HUD (ставится клиенту) |
| `plugins/` | исходники плагинов ServerMMO (Maven, Java 25) |
| `resourcepack/` | распакованный ресурспак: рамка, иконки, шрифт |
| `server/scripts/*.ps1` | служебные скрипты (скачивание ядра, проверка Java, бэкап) — их вызывают `.bat`-файлы |

## Быстрый старт (5 шагов)

1. **Установи Java 25** (64-bit). Для Minecraft 26.1 и новее нужна именно Java 25.
   Бесплатный вариант — Temurin JDK 25 от Adoptium:
   <https://adoptium.net/temurin/releases/?version=25>
   При установке оставь галочки **«Set JAVA_HOME»** и **«Add to PATH»**.
   *Если ты ставишь максимум Java 21 — сервер 26.3 не запустится, ему нужно 25.*
2. Скопируй папку `server` на Windows-ПК, например в `C:\mcsrv\`.
   Путь **не должен** содержать русских букв и пробелов, если можешь — лучше без них.
3. Двойной щелчок по **`start.bat`**. В первый раз он скачает `paper.jar` (~55 МБ).
4. Первый запуск занимает 1–3 минуты: генерируется мир (`world`), создаются
   `logs`, `config`, `banned-*.json` и т. д. Когда в окне появится
   `Done (XX.XXXs)! For help, type "help"` — сервер готов.
5. Проверь, что всё работает: запусти Minecraft **26.3** → Сетевая игра →
   Прямое подключение → `localhost`. Зайдёшь сам — значит, сервер жив.

Чтобы дать доступ друзьям — смотри раздел [Как зайти друзьям](#как-зайти-друзьям).

> Останавливать сервер нужно **командой `stop` в окне сервера** (или `Ctrl+C`
> с последующим `/stop`). Если просто закрыть окно, мир может повредиться.

## Настройки: `settings.bat`

Открывается любым текстовым редактором (Правка в Блокноте). После правки — сохранить
и снова запустить `start.bat`.

| Параметр | По умолчанию | Комментарий |
|---|---|---|
| `PAPER_VERSION` | `26.3` | Версия игры. Собранные под 26.3 билды Paper пока на канале **BETA** (рабочие, но не «финальные»). Хочешь максимально проверенную стабильность — поставь `26.2`, сервер тогда работает на 26.2, а игроки заходят клиентами 26.2 |
| `MIN_JAVA` | `25` | Минимальная версия Java для проверки. Менять вместе с версией игры (для 26.2 тоже 25) |
| `JAVA_CMD` | `java` | Обычно менять не нужно. Если `java` не в PATH — впиши полный путь, например `C:\Program Files\Eclipse Adoptium\jdk-25.0.1.9-hotspot\bin\java.exe` |
| `XMS` / `XMX` | `4G` / `4G` | Память сервера. `2G` — для пары друзей, `4G` — небольшой сервер до ~20 человек, `8G` — больше. Ставь XMS = XMX и **не давай серверу больше половины ОЗУ ПК** |
| `SERVER_JAR` | `paper.jar` | Имя файла ядра. Не меняй, если не знаешь зачем |
| `AUTO_RESTART` | `ask` | `ask` — спросит про перезапуск (автоответ «нет» через 20 с); `yes` — поднимать сервер заново после краша/остановки; `no` — просто закрыть окно |

Дополнительные флаги JVM в `JAVA_FLAGS` — официальные рекомендованные наборы для
Paper 26.3 (G1 GC). Трогать их необязательно.

## Что важно знать про Minecraft 26.3

* **Java 25** — обязательна (не 21, как раньше).
* **Белый список включён по умолчанию.** Mojang поменяла значение `white-list` на
  `true` в новых конфигах 26.3, и люди теряются, почему «никого не пускает».
  В нашем `server.properties` явно прописано `white-list=false` — если нужен
  закрытый сервер, поставь `true` и добавь игроков командой `whitelist add <ник>`.
* **Paper 26.3 — канал BETA.** Билды регулярно обновляются. Обновляй ядро командой
  `update.bat`, если что-то в логе просит или если известны баги. Автообновления
  ядра у Paper нет — только ручной запуск `update.bat`.
* **Клиент должен быть той же версии**, что и сервер. Сервер 26.3 — клиент 26.3.
  Хочешь пускать людей со старыми клиентами (или Bedrock-телефоны) — ставь
  плагины ViaVersion / Geyser.
* Мир, созданный на 26.3, потом нельзя «откатить» на 26.2 — при понижении версии
  мир не откроется. Перед сменой версии игры делай `backup.bat`.

## server.properties — на что смотреть

Полный список опций: <https://minecraft.wiki/w/Server.properties>. Самое частое:

| Параметр | Сейчас | Что значит |
|---|---|---|
| `motd` | `Paper 26.3 server \| welcome` | Название сервера в списке |
| `server-port` | `25565` | Порт. Если занят — поменяй (например на `25566`) и не забудь проброс портов |
| `max-players` | `20` | Лимит игроков |
| `gamemode` | `survival` | Режим по умолчанию |
| `difficulty` | `normal` | Сложность |
| `online-mode` | `true` | Проверка лицензии. **Не выключай**, если игроки заходят с лицензии |
| `enforce-secure-profile` | `true` | Если отключаешь `online-mode` (для пираток), выключи и это, иначе часть клиентов не зайдёт |
| `view-distance` / `simulation-distance` | `10` / `8` | Дальность прорисовки/симуляции. Ниже — меньше лагов |
| `white-list` | `false` | `true` — пускать только из списка |
| `management-server-enabled` | `false` | Управление сервером по JSON-RPC (порт 9900) выключено. Если в логе увидишь `Json-RPC ... listening on 0.0.0.0:9900` — просто закрой порт 9900 в брандмауэре |

## Как зайти друзьям

1. **Одна локальная сеть (Wi-Fi дома).** Друзья подключаются по твоему локальному
   IP: `ipconfig` → строка `IPv4-адрес`, например `192.168.0.15` → в игре
   `192.168.0.15:25565`.
2. **Через интернет — нужен проброс порта (port forwarding).**
   * В настройках роутера (обычно `192.168.1.1` или `192.168.0.1`) найди
     Port Forwarding / Виртуальные серверы.
   * Пробрось TCP-порт `25565` на локальный IP ПК с сервером. ПК лучше
     настроить на статический IP, иначе адрес «поедет».
   * Внешний адрес смотри на <https://2ip.ru> — друзьям давай его в формате
     `IP:25565`.
3. **Разреши сервер в брандмауэре Windows.** При первом запуске появится запрос —
   разреши для **частных** и **общедоступных** сетей. Если запрос пропустил:
   Брандмауэр Защитника Windows → «Разрешить работу с приложением» → добавь
   `java.exe` (или создай правило для TCP-порта 25565).
4. **Провайдер за NAT / нет белого IP?** Проброс не поможет. Варианты:
   Hamachi / Radmin VPN / ZeroTier / playit.gg — тогда друзья подключаются по
   выданному этими программами адресу.
5. Проверь доступность сервера снаружи: `ping <внешний IP>` в списке серверов
   должен показать мотд и число игроков (при `enable-status=true`).

**Стать оператором:** в окне сервера, где ты ввёл ник, набери
`op <твой_ник>`. Права оператора появятся после подключения заново.

## Плагины

Скачанные `.jar` клади в папку `server/plugins/`, затем останови сервер (`stop`)
и запусти снова. Проверяй, что плагин заявляет поддержку 26.3.

Стартовый набор, который обычно ставят: EssentialsX, LuckPerms, CoreProtect,
ViaVersion (+ViaBackwards), Geyser+Floodgate (для Bedrock), Chunky, Spark,
WorldEdit/WorldGuard, Simple Voice Chat. Подробнее — в `plugins/README.txt`.

### Свои плагины ServerMMO (уже в паке)

В `server/plugins/` лежат четыре готовых плагина — это кастомная система
здоровья, урона, уровней и HUD:

| Jar | Что делает |
|---|---|
| `servermmo-core-1.0.0.jar` | таблица 90 уровней, здоровье и урон на `long`, ванильные статы отключены |
| `servermmo-mobs-1.0.0.jar` | мобы видят игрока в радиусе 20 блоков, поворачивают голову и тело, бьют по кастомной системе |
| `servermmo-players-1.0.0.jar` | опыт за мобов, уровни, команда `/stats` |
| `servermmo-hud-1.0.0.jar` | рамка в левом верхнем углу: здоровье, урон, уровень, опыт |

Что изменилось в игре:

* ванильные сердца, броня, голод и полоска опыта в хотбаре больше не рисуются —
  вместо них рамка с цифрами;
* у мобов и игроков своё здоровье; удар вызывает покраснение и снимает его;
* моб умирает без анимации смерти и без дропа, только со звуком;
* за убийство моба дают опыт, при переполнении — новый уровень и полное лечение;
* игрок начинает с 20 HP / 5 урона / 0 из 200 опыта.

**Обязательно поставь ресурспак** — без него вместо рамки будут пустые квадраты.
Проще всего раздать его сервером (тогда игра сама предложит скачать), но можно и
вручную — оба варианта ниже.

### Как раздать ресурспак всем игрокам

Игра скачивает пак сама, если в `server.properties` есть **прямая ссылка** на файл
и его **SHA-1**. Ссылка должна открываться с компьютера игрока.

#### Вариант 1: мини-сервер из пака (рекомендуется)

Ничего устанавливать не нужно — используется та же Java, что и для сервера.

1. Двойной щелчок по `server/pack-server.bat`.
   Откроется окно, в нём будет примерно такое:

   ```
   ==================================================================
     ServerMMO resource pack server
   ==================================================================
     File:  ...\server\resourcepack\servermmo-hud.zip
     Size:  13418 bytes
     SHA-1: 5f742a5a945c2b1c33a6097e656dbdab1f7ffde2
     Port:  8080

     URL for players on the same network (LAN):
        http://192.168.1.50:8080/servermmo-hud.zip
   ```

   **Это окно нельзя закрывать**, пока играют люди — оно и есть сервер пака.

2. Двойной щелчок по `server/setup-resourcepack.bat`.
   Он спросит URL (Enter — подставить предложенный адрес), сам посчитает SHA-1 и
   запишет в `server.properties`:

   ```properties
   resource-pack=http://192.168.1.50:8080/servermmo-hud.zip
   resource-pack-sha1=5f742a5a945c2b1c33a6097e656dbdab1f7ffde2
   resource-pack-prompt={"text":"ServerMMO HUD resource pack","color":"gold"}
   require-resource-pack=false
   ```

   Старый файл сохраняется как `server.properties.bak`.

3. Запусти `server/start.bat` (настройки читаются при старте).
   Игрок при входе увидит предложение скачать пак, согласится — и получит рамку HUD.

**Что важно знать:**

* В локальной сети (домашний Wi-Fi) этого достаточно.
* Для игры **через интернет** нужно пробросить порт `8080` на роутере — так же,
  как порт `25565` для самого Minecraft. Либо используйте вариант 2.
* Порт задаётся в `server/settings.bat` (`PACK_PORT`, по умолчанию `8080`).
* Брандмауэр Windows спросит разрешение для `java.exe` — разрешить.
* Если игрок отказался от пака, он зайдёт, но HUD будет из пустых квадратов.

#### Вариант 2: публичный хостинг

Подходит, когда проброс порта недоступен или играет много людей. Залей
`servermmo-hud.zip` туда, где получится **прямая ссылка**, например:

* GitHub Pages в **публичном** репозитории;
* Cloudflare R2 / Yandex Object Storage / Selectel (публичный бакет);
* любой статический хостинг или веб-сервер.

Затем пропиши ссылку одной командой — SHA-1 посчитается сам:

```bat
setup-resourcepack.bat https://example.com/servermmo-hud.zip
```

> Ссылку с GitHub Release в **приватном** репозитории игроки открыть не смогут:
> клиент Minecraft не умеет авторизовываться в GitHub. Нужен публичный адрес.

#### Вариант 3: вручную каждому игроку

Без автоматики, но и без хостинга:

1. Скопируй `server/resourcepack/servermmo-hud.zip` в
   `%APPDATA%\.minecraft\resourcepacks` (Win+R → вставить этот путь).
2. В игре: **Настройки → Наборы ресурсов** → включить **ServerMMO HUD**.

#### Если хочется заставить, а не предлагать

Поставь `require-resource-pack=true` в `server.properties`: тогда игрок либо
принимает пак, либо его не пускает на сервер. Текст предложения меняется в
`resource-pack-prompt` (JSON-компонент; пиши только ASCII, иначе будут кракозябры).

#### Проверка

Открой ссылку из `server.properties` в браузере **на другом устройстве**
(например, телефон в том же Wi-Fi). Должен скачаться `servermmo-hud.zip`
на 13 418 байт. Если не скачивается — дело в адресе/порту, а не в Minecraft.

Команды: `/stats` — свои статы, `/stats <ник>` — чужие,
`/stats reset` — сброс к 1 уровню (оператор), `/hud scale|distance|offsetx|offsety`
— подстройка рамки под разрешение (оператор).

Настройки — в `plugins/ServerMMOCore/config.yml`, `plugins/ServerMMOMobs/config.yml`
и `plugins/ServerMMOHud/config.yml`. Полное описание — в
[`plugins/README.md`](plugins/README.md).

## Обновление ядра

* **Paper 26.3 → новее билд 26.3:** запусти `update.bat`. Он возьмёт последний
  билд с официального API PaperMC, скачает, проверит SHA-256 и заменит `paper.jar`
  (старое ядро останется как `paper.jar.old`).
* **26.3 → 26.4 (когда выйдет):** поменяй `PAPER_VERSION` в `settings.bat` на новую
  версию. При обновлении версии игры обязательно проверь требования к Java и
  сделай бэкап мира.
* **Откат на 26.2 (канал, где Paper уже STABLE):** укажи `PAPER_VERSION=26.2`,
  запусти `update.bat`. Мир обновится вниз не всегда корректно — лучше начать
  с бэкапа или нового мира.

## Бэкапы

`backup.bat` упаковывает `world*`, `plugins`, `config` и файлы настроек в
`backups/backup-<дата>.zip`. Запускай его:
* перед любым обновлением версии/ядра,
* перед сменой плагинов,
* периодически.

Если мир больше ~2 ГБ, `Compress-Archive` не справится с zip — сделай копию
вручную или запусти `scripts\backup.ps1` с параметром `-Mode copy`.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| Окно мигает и закрывается | Запусти `start.bat` из `cmd` вручную и прочитай текст, либо смотри `logs/latest.log`. Чаще всего — нет Java или не принята EULA |
| `UnsupportedClassVersionError` / просит более новую Java | Установлена Java 21 или старее. Нужна **Java 25** |
| `"java" не является внутренней или внешней командой` | Java не в PATH. Укажи полный путь в `JAVA_CMD` в `settings.bat` |
| Скачивание ядра не удалось | Проверь интернет/прокси, либо скачай jar вручную с <https://papermc.io/downloads/paper> и положи в папку как `paper.jar` |
| `You are not whitelisted on this server!` | Включён белый список (в 26.3 он по умолчанию `true`). В консоли: `whitelist add <ник>` или `whitelist off` |
| Не подключается по внешнему IP | Нет проброса порта, брандмауэр блокирует `java.exe`, либо провайдер за NAT (см. раздел выше) |
| Порт занят (`Address already in use`) | Другой сервер/программа на 25565. Поменяй `server-port` в `server.properties` |
| Лаги, низкий TPS | Уменьши `view-distance`/`simulation-distance`, проверь плагины профилировщиком Spark, не забудь поставить XMS = XMX |
| Мир не грузится после смены версии | Мир побывал в новой версии игры. Верни бэкап мира или запусти сервер той же версии, что и раньше |
| Экран «не отвечает», сервер долго стартует | Первый запуск: идёт генерация мира. Может занять несколько минут — это нормально |

## Если нужен сервер на Linux/macOS

В репозитории есть готовая версия скриптов под bash: папка [`linux/`](linux/).
Там `start.sh` делает всё то же самое (скачивание ядра, EULA, проверка Java,
автоперезапуск), плюс `update.sh` и `backup.sh`. Запуск:

```bash
chmod +x *.sh
./start.sh
```

## Структура репозитория

| Папка | Содержимое |
|---|---|
| `server/` | **готовый серверный пак для Windows** — копируй на ПК и запускай `start.bat` |
| `server/plugins/` | собранные плагины **ServerMMO** (`.jar`) |
| `server/resourcepack/` | готовый ресурспак `servermmo-hud.zip` |
| `plugins/` | исходники плагинов ServerMMO (Maven, Java 25) + описание |
| `resourcepack/` | исходники ресурспака: рамка, иконки, шрифт |
| `linux/` | то же самое для Linux/macOS (`start.sh`, `settings.sh`, `update.sh`, `backup.sh`) |
| `tools/` | тесты, линтер, генераторы статов и ресурспака |

### Проверка плагинов (для разработки)

```bash
python3 tools/check_plugins.py   # jar, таблицы статов, ресурспак
```

Сборка плагинов идёт в GitHub Actions: `.github/workflows/build-plugins.yml`
каждый push пересобирает четыре jar и кладёт их в `server/plugins/`.
Отдельный workflow `.github/workflows/smoke-test.yml` поднимает настоящий
Paper 26.3, ставит плагины, спавнит зомби и проверяет кастомный урон —
результат складывается в `smoke-test.log`.

### Проверка скриптов (для разработки)

Если правишь `start.bat` / `start.sh`, прогони тесты:

```bash
python3 tools/check_plugins.py  # проверка собранных jar, таблиц статов и ресурспака
python3 tools/gen_stats.py      # перегенерация stats.yml из tools/mobs_stats.txt
python3 tools/gen_resourcepack.py  # перерисовка и сборка ресурспака
python3 tools/lint-bats.py      # статические проверки .bat (метки, переменные, кавычки)
python3 tools/test-bats.py      # прогон логики .bat на мини-интерпретаторе batch + моках
bash    tools/test-linux.sh     # прогон linux/*.sh с подставными curl/java
```

Подробнее — в [`tools/README.md`](tools/README.md). Тесты не требуют ни
Windows, ни интернета: сеть и Java подменяются моками.
