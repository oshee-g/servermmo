# ServerMMO — плагины для Paper 26.3

Кастомная система здоровья, урона, уровней и HUD. Четыре связанных плагина плюс
ресурспак. Всё уже собрано и лежит в [`server/plugins/`](../server/plugins/), так что
для игры ничего компилировать не нужно.

---

## Что делают плагины

| Плагин | Jar | За что отвечает |
|---|---|---|
| **ServerMMOCore** | `servermmo-core-1.0.0.jar` | Таблица 90 уровней, кастомное здоровье и урон на `long`, профили игроков, ванильные статы отключены |
| **ServerMMOMobs** | `servermmo-mobs-1.0.0.jar` | Мобы замечают игрока в радиусе 20 блоков, поворачивают голову и тело, бьют по кастомной системе |
| **ServerMMOPlayers** | `servermmo-players-1.0.0.jar` | Опыт за убийство мобов, повышение уровня, команда `/stats` |
| **ServerMMOHud** | `servermmo-hud-1.0.0.jar` | Рамка в левом верхнем углу: здоровье, урон, уровень, опыт |

Зависимости простые: `mobs`, `players` и `hud` не включатся без `core`.
Paper сам выстроит порядок загрузки по `depend:` в `plugin.yml`.

## Как это работает

### Здоровье и урон

* У каждого игрока и моба есть **своё** здоровье, которое хранится в `long`
  (до 9 223 372 036 854 775 807). Ванильные `MAX_HEALTH`, `ATTACK_DAMAGE`,
  `ARMOR` обнуляются, чтобы не мешать.
* Любой ванильный урон отменяется и пересчитывается заново:
  * игрок бьёт моба — урон берётся из статов игрока (`player-stats.yml`);
  * моб бьёт игрока — урон берётся из таблицы мобов (`stats.yml`);
  * падение, лава, кактус, взрыв — ванильное значение ×
    `combat.environment-damage-scale` (по умолчанию 1:1).
* Удар вызывает ванильное покраснение и звук (`playHurtAnimation`).
* Когда кастомное здоровье кончается:
  * **моб** — проигрывается звук смерти, сущность исчезает. Анимации смерти и
    дропа нет вообще;
  * **игрок** — обычная ванильная смерть и респавн с полным здоровьем.

### Уровни и опыт

* Игрок начинает с **20 HP / 5 урона / 0 из 200 опыта** (как в макете HUD).
* За убийство моба даётся опыт из столбца «Опыт» таблицы.
* Когда опыт переполняет столбец «До след. уровня», игрок получает следующий
  уровень, полностью лечится и получает статы нового уровня.
* Со 2 уровня статы игрока совпадают с мобом того же уровня из таблицы.

### Мобы

* Каждый тип моба привязан к своему уровню: лосось — 1, курица — 2, …,
  хранитель — 90.
* Мобы ведут себя ванильно: ходят, плавают, стреляют, взрываются.
* **Все** мобы (включая мирных) замечают игрока в радиусе **20 блоков**:
  * враждебные получают цель и идут в атаку ванильным AI;
  * мирные и нейтральные идут к игроку через `Pathfinder` и бьют вручную,
    когда подошли;
  * все разворачивают тело (`setRotation`) и голову (`lookAt`) в сторону игрока.

### HUD

* Рамка, иконки (сердце, меч, `LVL`, кристалл) и цифры нарисованы в ресурспаке —
  это картинки, а не ванильные сердца.
* Значения живые: здоровье, базовый урон, уровень и `опыт/до следующего`.
* Ванильные сердца, броня, голод и полоса опыта в ресурспаке заменены
  прозрачными PNG — в хотбаре ничего не мешает.

## Установка

1. Скопируй `server/` на Windows-машину (или возьми готовый zip-пак).
2. Убедись, что в `server/plugins/` лежат четыре jar-файла `servermmo-*.jar`.
3. Запусти `start.bat`. В логе должно появиться:

   ```
   [ServerMMOCore] ServerMMOCore включён: уровней 90, статов игрока 90
   [ServerMMOMobs] ServerMMOMobs включён: радиус агро 20.0 блоков
   [ServerMMOPlayers] ServerMMOPlayers включён
   [ServerMMOHud] ServerMMOHud включён
   ```

4. Установи ресурспак (см. ниже) — без него вместо рамки будут пустые квадраты.

### Ресурспак

Файл: [`server/resourcepack/servermmo-hud.zip`](../server/resourcepack/servermmo-hud.zip)
(13418 байт, SHA-1 `d19a69e420b2861cbe7187833ae50c9bda26dba7`).

**Вариант А — вручную каждому игроку (проще всего):**

1. Скопируй `servermmo-hud.zip` в `.minecraft/resourcepacks`
   (Win+R → `%APPDATA%\.minecraft\resourcepacks`).
2. В игре: **Настройки → Наборы ресурсов** → включить «ServerMMO HUD» → Готово.

**Вариант Б — сервер раздаёт сам:**

1. Залей `servermmo-hud.zip` на любой хостинг, чтобы получилась прямая ссылка.
2. В `server.properties`:

   ```properties
   resource-pack=https://твой-хостинг/servermmo-hud.zip
   resource-pack-sha1=d19a69e420b2861cbe7187833ae50c9bda26dba7
   require-resource-pack=false
   ```

3. Перезапусти сервер. Клиент скачает пак при входе.

Посчитать SHA-1 самому: `Get-FileHash servermmo-hud.zip -Algorithm SHA1` (PowerShell).

> Если ресурспак не установлен, HUD покажет пустые квадраты вместо рамки и
> цифр, а ванильные сердца останутся на месте.

## Команды

| Команда | Право | Что делает |
|---|---|---|
| `/stats` | всем | свои уровень, здоровье, урон и опыт |
| `/stats <ник>` | всем | статы другого игрока |
| `/stats reset [ник]` | оператор | сброс к 1 уровню |
| `/hud scale 0.038` | оператор | размер рамки |
| `/hud distance 0.9` | оператор | расстояние до плоскости HUD |
| `/hud offsetx -0.40` | оператор | сдвиг влево/вправо |
| `/hud offsety 0.22` | оператор | сдвиг вверх/вниз |

`/hud` пишет значение в `plugins/ServerMMOHud/config.yml` и сразу применяет его.
Если рамка «улетела» за экран или слишком крупная — подстрой эти четыре числа
под своё разрешение и FOV.

## Настройки

### `plugins/ServerMMOCore/config.yml`

```yaml
debug: false

combat:
  environment-damage-scale: 1.0   # ванильный урон падения/лавы -> кастомный
  strip-vanilla-stats: true       # обнулять MAX_HEALTH, ATTACK_DAMAGE, ARMOR
  mob-death-sound: true           # звук смерти моба
  mob-death-animation: false      # анимация смерти (по ТЗ выключена)
  hurt-animation: true            # покраснение при ударе

storage:
  save-interval-seconds: 300      # автосохранение профилей
```

### `plugins/ServerMMOMobs/config.yml`

```yaml
aggression:
  radius: 20.0                 # радиус агро в блоках
  look-at-target: true         # поворот головы и тела
  peaceful-mobs-attack: true   # мирные тоже атакуют
  attack-cooldown-ticks: 20    # пауза между ударами (20 тиков = 1 сек)
  attack-reach: 2.6            # дальность удара
  follow-speed: 1.0            # скорость преследования
  check-interval-ticks: 10     # частота проверки
```

### `plugins/ServerMMOHud/config.yml`

```yaml
hud:
  distance: 0.9        # расстояние до плоскости HUD
  offset-x: -0.40      # влево от центра
  offset-y: 0.22       # вверх
  scale: 0.038         # размер
  update-interval-ticks: 2
  see-through: true    # рисовать поверх блоков

resource-pack:
  enabled: false       # автораздача пака (нужен url)
  url: ""
```

## Таблицы статов

### `plugins/ServerMMOCore/stats.yml`

90 уровней: `mob`, `type` (EntityType Paper), `health`, `damage`, `xp`,
`xp-to-next`. Пример:

```yaml
levels:
  1:
    mob: "Лосось"
    type: SALMON
    health: 3
    damage: 1
    xp: 4
    xp-to-next: 12
```

Файл можно править руками — плагин читает его при запуске. Если правишь
`tools/mobs_stats.txt` (исходную таблицу), перегенерируй:

```bash
python3 tools/gen_stats.py
```

### `plugins/ServerMMOCore/player-stats.yml`

То же для игрока. 1 уровень задан по макету HUD (20/5/200), дальше — как у мобов.
Правь свободно: `health`, `damage`, `xp-to-next`.

## Сборка из исходников

Исходники: [`plugins/`](.) — Maven-мультимодуль, Java 25, Paper API
`26.3.build.151-beta`.

```bash
mvn -f plugins/pom.xml clean package
```

Готовые jar появятся в `plugins/*/target/`. Скопируй их в `server/plugins/`.

Автоматическая сборка уже настроена в GitHub Actions
([`.github/workflows/build-plugins.yml`](../.github/workflows/build-plugins.yml)):
при каждом push, который меняет `plugins/`, Maven собирает все четыре jar и
коммитит их в `server/plugins/`. Если сборка падает — лог коммитится как
`build.log`.

### Проверка артефактов

```bash
python3 tools/check_plugins.py
```

Проверяет `plugin.yml` внутри jar, главные классы, api-version `26.3`, таблицы
90 уровней, формат ресурспака `97.1` и наличие всех глифов.

### Ресурспак из исходников

```bash
python3 tools/gen_resourcepack.py
```

Перерисовывает рамку, иконки и шрифт, собирает
`server/resourcepack/servermmo-hud.zip`.

## Порядок загрузки и совместимость

* Paper 26.3, Java 25.
* Плагины используют `plugin.yml` (не `paper-plugin.yml`) и `depend`, поэтому
  видят классы ядра напрямую.
* Если поставить только `servermmo-mobs.jar` без ядра, он выключится с записью
  `ServerMMOCore не загружен - выключаюсь`.
* Другие плагины (EssentialsX, WorldGuard и т.п.) работают как обычно, но их
  собственный урон тоже проходит через кастомную систему.

## Что можно докрутить дальше

* Регенерация здоровья вне боя.
* Своя шкала сложности: урон мобов в процентах от здоровья игрока.

* Опыт за добычу руды и крафт.
* Отдельные таблицы статов для мини-боссов.
